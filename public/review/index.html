Transcript and review cases

  1. Read context. ChatGPT lists the authorized synthetic budget's Cash USD and Cash LBP wallets and expense categories. Nothing is saved.
  2. USD expense. The user asks to record a $20 grocery expense from Cash USD. ChatGPT uses the hosted plugin and confirms the posted receipt.
  3. Receipt check. The user asks whether that expense saved using its original request ID. ChatGPT confirms the receipt without creating another entry.
  4. Income. A $500 income request is posted to Cash USD without an expense category.
  5. Lebanese pounds. A 150,000 LBP grocery expense is posted to Cash LBP, preserving the memo مشتريات تجريبية. LBP uses whole lira.
  6. Missing amount. “Add groceries from Cash USD today” prompts a clarification asking how much USD to record.
  7. Unsupported transfer. A bank transfer request is declined because the plugin records budget entries and cannot move money.
  8. Read-only request. ChatGPT shows available wallets for a $20 expense and saves nothing when explicitly instructed.

Saved demo entries were also checked directly in the demo budget. Hosted integration checks cover OAuth, wallet isolation, exact amounts, retry safety, and revocation. Review credentials are provided privately in the submission portal.
