# Mobile concept gallery

These 16 portrait layouts reflow the [revised desktop concepts](../desktop-concepts-v2/README.md) for a phone. They are generated design proposals based on the current React features, not screenshots of the running app. Names, dates, amounts, and URLs are illustrative. No product code was changed.

The proposed navigation has Home, Journal, a prominent Record action, Plan, and Manage in a fixed bottom bar. Loans is a section of Plan, alongside Allocation, Goals, Available cash, and Upcoming bills. Manage contains wallets, categories, household, phone setup, and account settings.

## Generation brief

The desktop page image was the visual reference for each mobile image. Each was regenerated for a portrait phone rather than cropped. The shared brief was a single-column layout with warm off-white canvas, white cards, deep charcoal text, emerald controls, readable financial amounts, and separate USD/LBP figures. Authentication and onboarding omit the app navigation; Record becomes a full-screen sheet. Each page prompt retained its core feature and action from the desktop gallery. The Plan prompts explicitly put Loans in Plan and remove it from Manage.

Generated artwork can contain illustrative copy or figures that are not product specifications. The layouts need UX review before implementation, especially the six-section Plan navigation on a narrow phone.
